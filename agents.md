# Agents Entry Point

Start here before doing any work in this repository.

## Pre-Flight Checklist

- check [context/tasks/index.md](./context/tasks/index.md)
- open the active phase document
- confirm the phase is approved before implementation
- confirm the next unit is eligible to start
- confirm no unresolved open decision blocks the unit
- confirm branch strategy before coding
- confirm the required guides for execution and completion have been read

## Read In This Order

## Context Structure

- `context/documentation/`
  Feature-level documentation.
- `context/archive/`
  Archived completed or superseded phase documents.
- `context/guides/`
  Orchestration, tracking, execution, completion, and engineering rules.
- `context/tasks/`
  Phase index plus one self-contained document per phase.

## Usage Rules

- Check `context/tasks/index.md` first to find the active phase and current status.
- Do not start a phase without confirming it is marked active.
- Use the phase document as the live source of truth for task status.
- Follow process rules from `context/guides/`.
- Follow feature docs from `context/documentation/`.
- Follow engineering rules from `context/guides/`.
