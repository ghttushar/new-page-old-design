# Archive

Completed or superseded phase documents should be moved here.

## Purpose

- keep `context/tasks/phases/` focused on active or upcoming work
- preserve historical phase context without cluttering current execution
- make it easy to review prior implementation decisions

## Rules

- move a phase here when it reaches `Archived`
- keep the original phase filename if possible
- do not delete archived phases unless there is an explicit cleanup decision
- update `context/tasks/index.md` when a phase is archived
