# Phase Template

Use this template when creating a new phase under `context/tasks/phases/`.

## Required Sections

1. Phase title
2. Phase status
3. Objective
4. Related references
5. Implementation preconditions
6. Scope checklist
7. Non-goals
8. Risks
9. Escalation triggers
10. URL or behavior contract when relevant
11. Assumptions
12. Open decisions
13. Decision log
14. Units
15. Verification approach
16. Completion checklist
17. Current status summary
18. Review checklist
19. Change log
20. Archive status or archive note when applicable

## Per-Unit Required Fields

- status
- owner
- dependencies
- next action
- exit criteria
- task list

## Summary Required Fields

- lifecycle state
- planning state
- review status
- implementation state
- active unit
- blocked units
- completed units
- current focus
