# Unit Update Template

Use this template when updating a unit inside an active phase document.

## Required Fields

- Status
- Owner
- Depends on
- Next action
- Exit criteria
- Tasks

## Optional Additions When Relevant

- Blocker note
- Assumption changes
- Verification note
- Commit reference

## Example Update Pattern

- move status to the new state
- update next action
- add blocker note if blocked
- record any changed assumption
- record verification gap if one exists
