# Verification Template

Use this template when defining verification for a phase or feature.

## Required Sections

1. Verification scope
2. Automated checks
3. Manual checks
4. State and routing checks if relevant
5. Error and empty-state checks
6. Known gaps
7. Skipped checks and reasons

## Common Checklist

- happy path works
- route state behaves correctly
- loading state behaves correctly
- empty state behaves correctly
- error or unavailable state behaves correctly
- regressions to protected or adjacent flows were checked
